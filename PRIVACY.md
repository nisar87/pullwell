# Privacy policy

Last updated: 2026-11-18

Pullwell is a download manager for Windows, with a browser extension ("Pullwell Downloads") for Chrome, Edge,
Brave, Chromium and Firefox. This page says what the program and the extension do with your information.

## The browser extension

- It does **not collect, store on any server, sell or share** personal data.
- It talks only to the Pullwell program running on your own computer (`127.0.0.1`), and to the website of a download
  you chose to send, so that the file can be fetched.
- For a download it passes the link, the page it came from, the browser's user agent and the cookies **of that
  download's site** to the Pullwell program on your computer. This is so downloads that need you to be signed in
  keep working. Nothing leaves your computer except the download request to that site itself.
- Settings (for example the minimum file size and the pairing with Pullwell) are kept in your browser's own
  extension storage.
- The `nativeMessaging` permission is used only to ask the browser to start the Pullwell program installed on your
  computer when a download needs it. It sends nothing else.
- It does not use analytics, advertising or tracking, and it loads no code from the internet.

## The Pullwell program

- It needs no account. The files you download, the download list and the settings stay on your computer.
- **Problem reports** are on by default, are shown once in the window before anything is sent, and can be turned
  off in `Options → Advanced → Send problem reports`. About every 6 hours, and after a crash, the new lines of the
  program's log are sent, with a random number made on your computer (not linked to you), the Pullwell and Windows
  versions, the processor count, the language and a few on/off settings. They never contain links, sites, file
  names, folders, your user or computer name, your downloads list, cookies or saved logins.
- The program checks GitHub for new versions of itself.
